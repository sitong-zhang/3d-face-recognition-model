Monocular 3D Reconstruction
一张 2D 照片，重建完整 3D 人脸

弥补普通手机没有 3D 结构光 / 深度摄像头的硬件限制——只靠一张普通照片，用算法估计深度，恢复出可旋转查看的完整 3D 人脸表面。

478 个 3D 锚点（MediaPipe Face Mesh） 官方 898 面拓扑连成连续曲面 鼻尖原点归一化 自研纯软件渲染 · 零皮肤纹理 OBJ / PLY 导出

从一张 2D 人脸照片即可估计出完整 3D 网格（深度由算法估计，非硬件深度摄像头）：正面呈现鼻梁、眼窝、嘴与下巴轮廓，侧面呈现面部起伏。支持导出 OBJ / PLY 模型，用于多视角查看与 3D 身份比对。

How to use
三步完成验证

命名并录入

点「录入人脸」，输入姓名，把脸放进环形取景框，按引导缓慢转头，进度环填满即完成 3D 建模。

扫描识别

点「扫描人脸」正对镜头，系统与你录入的每个人比对，通过后灵动岛弹出绿色对勾动画。

看到姓名

识别成功后，屏幕下方会显示此人的姓名——认得出你，也叫得出名字。

Why Face3D
产品优势

让每一部手机都拥有 3D 人脸能力

  • 无需 3D 结构光或深度摄像头，普通手机相机即可完成基于算法估计深度的 3D 人脸建模与识别。
  • 每位使用者拥有独立重建的 3D 人脸模型，几何特征各不相同，用于区分身份。
  • 512D 判别式人脸特征，亮度、角度变化下保持稳定识别。
  • Face ID 风格交互：80 段环形采集、灵动岛胶囊验证、对勾与失败摇头动效（素材来自开源 Glance）。
  • 全部计算在设备本地完成，人脸数据不上传，隐私有保障。
