Features
简单两步，安全验证

没有复杂的设置，打开应用即可使用。所有处理都在设备本地完成。

录入人脸

通过相机采集面部，提取 478 个 3D 关键点作为几何特征，安全保存在本机。

扫描验证

将当前 3D 特征与录入特征比对，实时反馈相似度与成功 / 失败结果。

Face ID 动画

成功时播放绿色圆环与对勾绘制动画，还原苹果 Face ID 的顺滑视觉体验。

How to use
三步完成验证

安装并打开

下载 APK 安装到手机（允许安装未知来源），首次打开授予相机权限。

录入人脸

点击「录入人脸」，正对镜头，让面部位于圆圈内，等待录入成功。

扫描验证

点击「扫描人脸」，同样正对镜头，通过后即可看到绿色对勾成功动画。

Honest notes
诚实的说明

不夸大 · 不编造

  • 人脸比对基于 478 点 3D 几何特征的相似度，属演示级方案，并非论文级身份识别模型。
  • Face ID 动画为 UI 视觉效果，不代表具备苹果设备硬件级的深度摄像头与活体检测能力。
  • 3D 人脸能力来自 MediaPipe 开源项目（Apache 2.0），本应用只做封装与集成，已如实署名。
  • 结果受光线、角度、遮挡影响；相似度阈值可按实际场景调整。
